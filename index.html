rusty_snake · systems / game
Rusty Snake 🐍
A terminal-based Snake game written entirely in Rust — my first deep dive into the language. The project explores Rust's ownership model, struct-based game state, and low-level terminal rendering via crossterm. Every frame is a lesson in memory safety, zero-cost abstractions, and systems-level thinking.
Built as part of a broader mission: understand Rust's borrow checker from the ground up before touching higher-level tooling. Simple concept, serious learning.
